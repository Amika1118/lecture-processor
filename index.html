🔑 Get your FREE Groq API Key

Follow these steps (no credit card required):

  1. Go to console.groq.com
  2. Sign up using Google, GitHub, or email
  3. Once logged in, click on API Keys in the left sidebar
  4. Click Create API Key
  5. Give it a name (e.g., "Lecture Processor") and click Create
  6. Copy the key (it starts with gsk_)
  7. Paste it into the API key field on this page
